## 🎯 使用方法

### **步骤1: 部署文档到GitHub Pages**
1. 创建GitHub仓库: `cryptoai-assistant`
2. 将本文件夹所有文件上传
3. 启用GitHub Pages
4. 获取文档URL:
   - 服务条款: `https://your-username.github.io/cryptoai-assistant/terms_of_service.html`
   - 隐私政策: `https://your-username.github.io/cryptoai-assistant/privacy_policy.html`

### **步骤2: 填写TikTok开发者表单**
使用 `form_fields.md` 中的内容逐项填写。

### **步骤3: 录制演示视频**
按照 `demo_video_script.md` 录制1-2分钟演示视频。

### **步骤4: 提交审核**
检查 `submission_checklist.md` 确认所有项目已完成。

---

## ⚠️ 重要提醒

### **合规性关键点**
1. **所有内容仅供教育目的**: 强调 "For entertainment and educational purposes only"
2. **非财务建议**: 避免使用 "investment", "trading", "profit" 等词
3. **年龄限制**: 目标受众 18+
4. **数据安全**: 明确说明数据收集最小化

### **审核要点**
1. **演示视频必须展示完整流程**: 从内容生成到TikTok上传
2. **域名匹配**: 视频中展示的网站域名必须与提供的URL匹配
3. **产品范围一致**: 只申请实际需要的API权限
